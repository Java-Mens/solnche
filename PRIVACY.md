# Политика конфиденциальности

**СОЛНЦЕМЕР (Solntsemer)** — приложение для отображения истинного местного солнечного времени.

## Сбор данных

Приложение **не собирает**, **не отправляет** и **не хранит на внешних серверах** никакие персональные данные.

## Геолокация

- Геолокация (координаты GPS/сети) обрабатывается **только на устройстве** для расчёта истинного солнечного времени.
- Координаты **не отправляются** на внешние серверы.
- Координаты сохраняются локально (SharedPreferences) для восстановления состояния между запусками.

## Сетевые запросы

Приложение **не выполняет** сетевые запросы в текущей версии. Все астрономические расчёты выполняются локально.

## Разрешения

- `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` — для определения текущего местоположения (опционально; можно ввести координаты вручную)
- `INTERNET` / `ACCESS_NETWORK_STATE` — зарезервировано для будущих версий (карта OSM, обновление DUT1)

## Сторонние сервисы

- Не используются Google Play Services
- Не используются сторонние трекеры, аналитика, реклама
- Не используются проприетарные карты
